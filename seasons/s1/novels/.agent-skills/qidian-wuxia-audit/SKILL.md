# 起点中文网武侠投稿专项审核器

## 目标
不只判断“写得好不好”，而要判断：
- 能不能挂在起点读下去
- 有没有武侠辨识度
- 有没有追读驱动
- 有没有审核风险

## 核心检查

### 1. 开篇留存检查
- 前100字是否有异样/命令/危险/冲突
- 前300字是否出现人物+动作 或 人物+悬念
- 前800字主角是否主动推进一步
- 前1500字是否给出一次明确兑现

### 2. 主角有效性检查
- 主角是否有判断
- 主角是否有手段
- 主角是否有魅力
- 主角是否主动改变局势，而不只是被局势拖着走

### 3. 武侠辨识度检查
每章至少落一项：
- 兵器
- 身法
- 拆招
- 江湖规矩
- 门派旧怨
- 名号压力

### 0. 字数底线检查
- 《沸腾之雪》正文章节（不含序幕）默认不少于 2000 字
- 低于 2000 字默认判定为“章节功能未完成”，除非用户明确要求短章
- 2000-2600 字：可发布下限
- 2600-3500 字：当前推荐舒适区

### 4. 爽点兑现检查
- 本章有没有即时满足感
- 是否至少兑现一个小结果
- 是否只是铺局不落子

### 4.5 情绪与活人味检查
- 是否至少给出一个可记住的情绪点：鼻酸 / 发热 / 失而复得 / 死地前松一口气
- 高压章节里是否保留一点活人气：老兵粗话 / 同袍互损 / 黑色幽默 / 死地前浑话
- 幽默是否来自人物处境，而不是现代网梗抖机灵
- 夜惊鸿这类压场人物是否仍保持克制，避免碎嘴塌气场

### 5. 追读检查
- 章尾是否形成连续阅读冲动
- 下一章问题是否清晰
- 是否只有意境，没有动作后续

### 6. 商业化标题检查
- 是否适合推荐位点击
- 是否含有具体卖点
- 是否避免空泛标题

### 7. 平台禁线检查
重点排查：
- 政治敏感映射
- 淫秽擦边
- 极端暴力血腥堆砌
- 现实民族/群体风险表达
- 价值导向失衡

### 8. AI味/模仿味检查
- 是否过像某头部爆款
- 是否有模板句堆砌感
- 是否存在“漂亮但空”的AI腔

## 结论输出模板
```markdown

是否具备首发可读性：是 / 否

字数是否达标：达标 / 不达标
武侠辨识度：强 / 中 / 弱
审核风险：低 / 中 / 高

最大问题：
1.
2.
3.

最该先改：
- 开头 / 中段 / 章尾 / 主角动作 / 标题
```

## 禁止项
- 禁止连续两章只铺局不落子
- 禁止主角连续两章没有主动行为
- 禁止整章最大价值只有氛围感
- 禁止靠隐藏身份反复单线程吊胃口
- 禁止战斗只有“快狠冷重”，没有判断与变化
- 禁止朝堂戏长期压过江湖戏
- 禁止章末只有意境，没有动作后续
- 禁止明显模仿头部作品句式
- 禁止全章只有高压，没有活人气与情绪起伏
- 禁止把接地气写成现代段子合集或油腔滑调

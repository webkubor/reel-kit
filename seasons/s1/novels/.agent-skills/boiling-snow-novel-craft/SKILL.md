# 沸腾之雪 · 单章构思

## 一、职责边界

这份 skill 只负责：
- 想清楚这一章为什么存在
- 这一章到底在表达什么
- 用什么事件承载这一章
- 用谁的视角最合适

它不负责：
- 项目总设定真假 → 交给 `boiling-snow-writing`
- 章节完整流程 → 交给 `novel-flow`
- 纯文笔句子优化 → 交给 `写手中枢`
- 起标题 → 交给 `起名中枢`

一句话：
**它只管“这一章怎么想”，不管“这一章怎么写得漂亮”。**

---

## 二、核心方法

### 铁律：先定核心思想，再定事件，再定视角

顺序不能反。

1. **核心思想**
这一章到底要传达什么？一句话说清楚。

2. **承载事件**
用什么具体事件，把这个思想落到人命上？

3. **视角人物**
谁来看这件事，最痛、最准、最值？

错误顺序：
- 先想画面
- 先想一句很帅的话
- 先想设定怎么抖出来

正确顺序：
- 先想这一章到底要让读者感受到什么

---

## 三、判断一章是否成立的标准

一章成立，不是因为“有画面”，而是因为它完成了一次明确表达。

每次构思都先回答这四个问题：
1. 这章的核心思想是什么？
2. 这章的主要事件是什么？
3. 这章结束后，人物关系发生了什么变化？
4. 这章结尾，读者为什么还想往下看？

如果答不出来，就说明这一章还不能写。

---

## 四、隐藏身份章节链路校准

当章节任务不是“打一场仗”，而是“让一群人逐步重新认识一个人”时，必须先把递进链路定死，再写事件。

### 铁律：认识 ≠ 接受 ≠ 怀疑 ≠ 认出

如果这四步被提前合并，后面章节会直接失去价值。

适用于《沸腾之雪》这类双身份人物（如苏梦城 / 夜惊鸿）：

1. **认识**
   - 只是第一次见到这个人
   - 知道他很强、是王府请出来镇场的人
   - 不能提前把他和苏梦城本人连上

2. **接受**
   - 接受的是能力，不是身份
   - 要写成：这人真能带路、真懂战场、真能压阵
   - 不能写成：大家已经默认他是谁

3. **怀疑**
   - 怀疑来自细节重复，不来自作者抢答
   - 应靠：行军口令、看风习惯、压队方式、枪路、旧话、旧兵反应
   - 这一层只能写“越来越像”，不能写“已经对上”

4. **认出**
   - 必须有明确落锤点
   - 应靠老兵身体记忆、旧令、旧习惯、只有当事人才懂的话
   - 认出后也不等于公开喊破，很多时候要写成心照不宣

### 公开口径与真实身份必须分开写

如果项目里有“双身份 / 假身份 / 外界误认”结构，必须同时写清两套认知：

- **读者此章知道多少**
- **场内人物此章知道多少**

尤其注意：
- 不能因为作者知道答案，就让角色提前显得知道答案
- 不能让旁白提前替角色完成“认出”
- 不能在“接受阶段”偷写成“怀疑阶段”
- 不能在“怀疑阶段”偷写成“认出阶段”

### 《沸腾之雪》里最常见的错误

1. 让将校、旧部太早把银面人直接当成王爷
2. 让旁白太早说出“夜惊鸿就是谁”
3. 让群体心理一步完成，不经过“先服本事，再起疑心”的过程
4. 用一句解释直接说破，代替老兵慢慢识破

### 自检问题

如果这一章涉及隐藏身份推进，写前先问：
1. 这一章推进的是“认识 / 接受 / 怀疑 / 认出”哪一步？
2. 这一章有没有越级？
3. 群体变化是一起完成，还是有先后层次？
4. 这一章最值钱的是“能力被接受”，还是“身份被看穿”？
5. 作者有没有替角色抢答？

一句话收束：
**隐藏身份不是用来一次揭开的，而是用来让不同人以不同速度慢慢逼近的。**

## 五、适合《沸腾之雪》的章节类型

### 1. 命线启动章
作用：让某个人真正卷入局里
适合：第一章、人物入局章

### 2. 关系加深章
作用：不靠讲背景，而靠事件让关系更复杂
适合：苏梦城/顾栖月、慕夕歌/宁观尘、苏梦城/寒江淮等线

### 3. 代价兑现章
作用：让人物开始为前面的选择付代价
适合：死亡、误会、失去、背叛前后

### 4. 真相逼近章
作用：不直接公布真相，而是让读者意识到有人快看见了
适合：旧案、花案、孤山旧债、王府暗线

### 5. 风雪压城章
作用：用外部局势推动人物必须表态
适合：欧阳狂徒压境、朝堂逼问、边线崩盘等

## 五、视角选择原则

### 选视角，不看“谁重要”，看“谁最值”

优先选择：
- 最靠近伤口的人
- 最容易感受到这件事代价的人
- 最能让读者误会或迟一步看清的人

不优先选择：
- 设定最强的人
- 只是方便讲背景的人
- 作者最想借来解释世界观的人

### 简单判断法
如果这一章是：
- 朝堂逼压 → 优先苏梦城视角
- 情感错位 → 优先关系里更迟钝或更压抑的人
- 真相逼近 → 优先只看到半截真相的人
- 大局压来 → 优先最先被局砸中的人

---

## 六、事件选择原则

### 事件必须能承载思想

不要用“漂亮场景”代替事件。

错误：
- 下雪了
- 三个人沉默
- 灯很冷
- 氛围很好

正确：
- 有人来传旨
- 某人被外派
- 一封信进了府
- 某个旧名字被重新提起
- 一个人必须做选择

一句话：
**没有事件，所有氛围都会空。**

---

## 七、《沸腾之雪》第一章构思禁忌

第一章尤其要克制。

禁止：
- 一上来把所有人都抖出来
- 一上来解释完整背景
- 一上来揭穿隐藏身份
- 章尾把答案直接说完
- 只写气氛，没有事发生

允许：
- 先给天下局势，再迅速落到具体场景
- 先给异样，再不给答案
- 用一场具体事件，把主角推上局面

一句话：
**第一章的任务是立局，不是立百科。**

---

## 八、单章构思输出模板

每章写之前，先写这份：

```markdown
## 第X章 构思卡

### 核心思想
（一句话）

### 主要事件
（这章真正发生什么）

### 视角人物
（谁来看这章）

### 人物关系变化
（章前 vs 章后）

### 本章最值钱的东西
（是动作、关系、异常、代价，还是悬念）

### 章尾钩子
（不要抢答，只开门）
```

没有这张卡，不进正文。

---

## 九、自检问题

写这一章前，先问：
1. 我这章到底想表达什么？
2. 这章有没有真正发生一件事？
3. 这章是不是在用设定代替人物？
4. 章尾是不是在开门，而不是抢答？
5. 如果删掉这章，会不会影响人物命线？

如果删掉不影响，那这章大概率不成立。

---

## 十、最终标准

一章写对了，应该出现这四个结果：
- 人物更立住了
- 关系更变复杂了
- 局势更往前推了
- 读者更想看下一章了

一句话收束：
**这一章不是用来堆信息的，是用来让人物的命往前挪一步的。**

# 沸腾之雪 · 项目总原则

## 一、职责边界

这份 skill 只负责三件事：
1. 统一《沸腾之雪》的创作气质
2. 统一这本书的结构原则
3. 守住不能写错的项目硬约束

它不负责：
- 具体章节怎么起承转合 → 交给 `boiling-snow-novel-craft`
- 章节流程怎么走 → 交给 `novel-flow`
- 纯文笔优化 → 交给 `写手中枢`
- 起标题/卷名 → 交给 `起名中枢`

一句话：
**它只管“这本书怎么写才像《沸腾之雪》、怎么写才不歪”。**

---

## 二、这本书真正的气质

《沸腾之雪》不是爽文争霸，也不是玄幻高武。

它的底色是：
- 旧债
- 宿命
- 误会
- 情仇
- 王权与江湖互相绞杀
- 很多人会死，而且死得有代价

写这本书时，始终记住：
**先写人被命推着走，再让世界观从人的命里渗出来。**

### 文风关键词
- 冷
- 准
- 硬
- 稳
- 留白
- 有后劲

### 绝对避免
- 说明书口气
- 假文青
- 自我感动
- 先把答案讲完
- 把设定直接堆到读者脸上
- 玄幻光效感

---

## 三、叙事结构原则

### 1. 主线原则
- 正文主线：正序推进
- 旧案揭露：碎片倒灌
- 不用大段历史课式回忆
- 不用一上来就把二十年前讲透

### 2. 正确的总时间结构
- 二十年前：老剑神那一代埋因
- 乾明十七年：局开始转，夜惊鸿真正进入天下视野
- 后面很多年：关系、误会、死亡、结仇逐步升级
- 最终：三绝绝战

### 3. 第一卷定位
第一卷不是终局前夜，而是：
**旧局开门。**

写的是：
- 欧阳狂徒压境
- 南楚无人敢接
- 寒江淮重新想起苏梦城
- 苏梦城借此局把夜惊鸿真正推入天下视野

### 4. 前三章铁律
前三章的任务不是“把所有设定压进去”，而是“把门推开，把人立住，把读者留下来”。

必须满足：
- 优先聚焦苏梦城主线，但允许一章只完成一个清晰任务
- 必须有具体事件，不要纯氛围空转
- 前三章的核心目标是：
  - 第1章：开门，立王爷与局势
  - 第2章：起势，立旧部、身份反差与军心变化
  - 第3章：进关前，立战场判断与危险压迫
- 不要求前三章把世界观、三绝、旧债、王府、黑市、顾栖月、慕夕歌全部一次讲完
- 宁可少讲一点，也不要为了“交代清楚”把人物压成设定卡
- 进入具体场景后，优先落人物动作、反应、细节，再让设定慢慢渗出来
- 章尾只留风声、去向、动作、物件、未说破的消息
- 禁止在前几章为了赶进度，强行塞满人物和信息
- 禁止把“用户提出的点”机械拆单执行成任务清单式写作

一句话：
**前三章最重要的不是信息量，而是人物要活、局要紧、读者要想往下翻。**

### 5. 第一章章尾实战修正
- 可以写：旧屋重新亮灯、黑市风声起、有人今夜出城、某物被取出、某句话被顺着风递出去
- 不可以写：直接点明隐藏身份、直接报出隐藏名号、直接亮出银面/长枪等关键答案性物件
- 好的第一章结尾，不是“读者知道真相了”，而是“读者知道今晚要出大事，但还差半步没看见”

### 6. 体量与切章修正
- 第一章优先控制在 2500-3200 字
- 若一章明显塞入两章内容，不要硬切一半后直接当第二章；必须把切出来的章节重写成独立完整章
- 第二章不能只是“第一章后半截残片”，必须有自己的推进、关系变化或新钩子
- 判断标准：删掉这一章后，人物命线是否少走了一步；若没有，就说明这一章还不够成立

## 四、项目硬约束

### 1. 主角与核心人物
- 男主：苏梦城
- 女主：顾栖月
- 三绝：慕北歌、夜惊鸿、欧阳狂徒
- 慕夕歌是“因”，是导火索，不是长期主视角中心

### 2. 身份关系
- 苏梦城 = 夜惊鸿（本质同一人）
- 但在乾明十七年前后，天下并不知道，寒江淮也未识破
- 外界合理认知应是：苏王爷暗地里养着/借着夜惊鸿这把刀
- 不能写成所有人很早就看穿

### 3. 苏梦城关键线
- 父死
- 从军
- 战功赫赫封王
- 自愿自废武功表忠心
- 母亲被宫里人下毒手
- 一夜白头
- 追查毒案，线索落在“一朵花”上
- 欧阳狂徒连败南楚大将后，被寒江淮重新推上局面
- 皇帝只给他三千轻骑
- 夜惊鸿借这一局真正成名

### 4. 顾栖月关键线
- 顾栖月认识和被救时，对应黑发苏梦城阶段
- 回王府时，见到的是白发王爷
- 她不是立刻知道夜惊鸿身份
- 某一阶段她被外派去查“花案”
- 这一阶段不能同时写成她留守王府陪侍苏梦城

### 5. 慕夕歌关键线
- 慕夕歌下山时，苏梦城已经是白发状态
- 她与宁观尘线属于“近几年发生的事”，不是很多年前
- 她的死法细节可后补，但性质已定：她是孤山死局中的承灾者之一

### 6. 王府与丹阳
- 王府在丹阳城，离宫门不过三条长街
- 这是南楚建国以来第一个、也是唯一一个设在京城的异姓王府
- 皇帝自封王后从未踏入苏王府半步
- 朝廷官员避之不及
- 丹阳百姓却普遍亲近苏王府
- 所以王府在京城具有双重地位：
  - 朝堂眼里的是非地
  - 百姓口中的有情之府

## 五、写作时的几个高级判断

### 1. 什么时候解释
- 人物命已经卷进去时再解释
- 没卷进去时，只给异样，不给答案

### 2. 什么时候写世界观
- 不单独讲
- 借战报、路程、城池、官话、旧物、人物偏见慢慢露

### 3. 什么时候用回忆
只在三种情况用：
- 情绪被触发
- 物件被触发
- 对抗被触发

### 4. 什么叫写歪了
一旦出现以下情况，基本就是歪了：
- 一章里解释太多
- 人物像设定卡，不像活人
- 章尾提前揭底
- 江湖写成玄幻
- 朝堂写成空泛宫斗
- 所有人都比读者懂得更多

---

## 六、调用方式

当要写《沸腾之雪》时，先用这份 skill 做三件事：
1. 校对这章有没有违背项目硬约束
2. 校对这章的结构是不是“先立人，再渗设定”
3. 校对章尾是不是在留钩子，而不是抢答

然后再去调用：
- `boiling-snow-novel-craft` 做单章构思
- `novel-flow` 跑流程
- `写手中枢` 做文笔收束
- `起名中枢` 做命名

---

## 七、最终标准

如果一章写对了，它应该同时满足：
- 读者先被人抓住，不是先被设定砸住
- 世界观是渗出来的，不是讲出来的
- 每个人都有自己的气口，不像工具人
- 收尾让人想翻下一章，而不是觉得答案都看完了

一句话收束：
**《沸腾之雪》写的不是“谁最强”，而是“谁被旧雪埋了一生，又在最后把雪烧沸了”。**

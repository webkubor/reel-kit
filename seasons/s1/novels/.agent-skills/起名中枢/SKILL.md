# 起名中枢

## 职责边界

只负责命名：
- 章节名
- 卷名
- 序幕名
- 人物称号
- 文档标题

不负责：
- 具体剧情设计
- 时间线判断
- 文笔润色

## 命名目标

好名字必须至少满足三条：
1. 好记
2. 有画面
3. 有钩子
4. 不俗套
5. 符合项目气质

## 命名原则

### 1. 先看这一章最值钱的东西
章节名优先抓：
- 核心动作
- 核心异常
- 核心物件
- 核心处境

不要抓：
- 大而空的主题词
- 一眼看完就忘的普通词

### 2. 名字不要把答案说完
好标题是“把门推开”。
不是“把剧情总结一遍”。

### 3. 先具体，再文气
优先：
- 三千轻骑
- 雪夜召王
- 灯下白发
- 宫门急雪

少用：
- 风雪惊变
- 宿命之战
- 命运转折
- 江湖震动

### 4. 章节名优先短
最佳区间：
- 2字
- 4字
- 6字内

## 章节名三型

### A. 物件/画面型
适合开篇、收气质
例：
- 白发王爷
- 三千轻骑
- 旧屋灯火
- 一纸血书

### B. 动作/事件型
适合推进剧情
例：
- 雪夜召王
- 轻骑出城
- 四关尽破
- 宫门传旨

### C. 异常/悬念型
适合章尾强钩
例：
- 那位爷
- 第一道关
- 不该来的信
- 今夜出城

## 本项目偏好

《沸腾之雪》命名应偏：
- 冷
- 硬
- 有画面
- 不空
- 不俗

避免：
- 太像通用网文模板
- 太像散文标题
- 太像解释句

## 自检问题

在定名字前先问：
1. 这个名字能不能让人想点开下一章？
2. 这个名字是不是太普通，换一本到处都能用？
3. 这个名字是不是把剧情说太满了？
4. 这个名字有没有《沸腾之雪》的冷感？

## 输出格式

每次给名字，至少提供：
- 稳版（最能落地）
- 钩子版（最有悬念）
- 气质版（最贴项目）

并明确推荐哪一个，为什么。


## 平台点击率检查

在起点目录与推荐位上，标题还要额外满足：
- [ ] 一眼能看出本章卖点
- [ ] 含具体名词/动作/异常中的至少一个
- [ ] 有武侠感，不是泛古风感
- [ ] 连续十章看下来不会一个味
- [ ] 避免大词空词

### 平台向禁止项
- 禁止章名连续三章都偏同类意象词
- 禁止纯散文式标题
- 禁止太像影视分集名
- 禁止“风雪/宿命/长夜/天下/江湖”高频空泛词滥用

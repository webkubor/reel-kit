# 小说创作标准流水线（起点武侠适配版）

> 适用：任何《沸腾之雪》章节创作与审核
> 调度：boiling-snow-writing（项目总原则）+ 写手中枢 + 起名中枢
> 目标：不是只写得对，而是写得能让起点读者追下去

---

## 六阶段流水线

> ⚠️ 标题必须先调研再定，禁止直接使用微短剧（boiling-snow-film）里的标题。

Stage 0：看上一章
- 输入：上一章正文
- 输出：情节点摘要 / 人物状态 / 未兑现钩子 / 本章起点

Stage 1：Beat Sheet
- 输入：本章目标
- 输出：本章结构、卖点、兑现点、追读点

Stage 2：标题与开头钩子
- 输入：Beat Sheet
- 输出：章名三选一 + 前300/800字抓力设计 + 章尾钩子

Stage 3：逻辑冲突检查
- 输入：标题结果 + 设定/人物/时间线
- 输出：冲突清单；有冲突不得进写稿

Stage 4：写稿
- 输入：已定标题、结构、钩子
- 输出：正文草稿

Stage 5：平台审核
- 输入：正文草稿
- 输出：八维评分 + 起点读感结论 + 修改优先级

---

## Stage 1：Beat Sheet

### 输出模板
```markdown
## 第X章 Beat Sheet

**本章平台目标**：首读留存章 / 追读章 / 转折章 / 爽点章 / 关系推进章 / 付费前蓄势章
**本章显性卖点**：刀 / 局 / 仇 / 身份 / 破关 / 对峙 / 旧案 / 误会（至少一个）
**主线目标**：
**视角人物**：

### 四段结构
- 建置（前300字）：
- 推进（300-1200字）：
- 小高潮（1200-2200字）：
- 收尾钩子（最后300字）：

**本章即时回报**：读者这一章看完最值的是什么
**目标字数**：正文章节默认 2000-3500 字；其中 2200-3200 字为推荐舒适区
**本章追读驱动**：下一章读者最想知道什么
**主角有效动作**：这一章主角主动做了什么
**武侠要素落点**：兵器 / 身法 / 拆招 / 江湖规矩 / 门派旧怨 / 名号压力
**人物关系变化**：
**风险提示**：
```

### 必查项
- [ ] 前300字有事发生
- [ ] 前800字主角有明确动作或决定
- [ ] 本章不是只铺气氛，必须有兑现点
- [ ] 本章至少有一个武侠识别点
- [ ] 本章结尾能逼出下一章

---

## Stage 2：标题与钩子

### 标题三选一
1. 稳版：最能落地
2. 钩子版：最能驱动追读
3. 气质版：最贴《沸腾之雪》

### 标题检查
- [ ] 一眼能看出本章卖点
- [ ] 不是空泛词（宿命、风云、震动、传奇）
- [ ] 最好包含具体人/物/动作/异常中的至少一个
- [ ] 适合起点目录点击，而不只是文气好看

### 开头抓力设计
- 前100字：必须有异样、命令、危险、冲突四选一
- 前300字：必须出现人物+动作 或 人物+悬念
- 前800字：主角必须有效推进一步

### 章尾钩子设计
允许：
- 新敌人
- 新信息
- 新误会
- 新命令
- 新代价

禁止：
- 只有意境，没有动作后续
- 直接公布底牌答案
- 只靠隐藏身份单点吊胃口

---

## Stage 3：逻辑冲突检查

### 设定检查
- [ ] 与上一章衔接是否矛盾
- [ ] 人物位置/状态/武力是否自洽
- [ ] 世界规则是否被破坏
- [ ] 时间线是否冲突
- [ ] 章末状态到下一章开头之间，是否缺少必要的“认知过桥 / 身份过桥 / 行动过桥”
- [ ] 角色知道多少、旁观者知道多少、读者知道多少，三者是否分层清楚
- [ ] 本章是否提前喊破下一章才该兑现的身份、关系或悬念

### 读感检查
- [ ] 读者是否能在一章内明白本章目标
- [ ] 人物动机是否当章可理解
- [ ] 是否出现“作者知道但读者不知道，所以角色显得假聪明”
- [ ] 是否出现“作者旁白抢跑”，提前替角色完成命名、确认或落锤
- [ ] 战斗是否有代价 / 地形 / 信息差支撑
- [ ] 朝堂信息密度是否压过江湖感
- [ ] 本章是否至少有一个可记住的情绪点（鼻酸/发热/苦中作乐/死地前松气）
- [ ] 高压段落里是否保留一点活人味，而不是整章只剩硬压与苦大仇深
- [ ] 正文是否全程高压；是否需要补一口活人气、接地气对白或黑色幽默来泄压
---

## Stage 4：写稿自检

### 十一项自检
- [ ] 正文章节不少于2000字（除非用户明确要求短章）
- [ ] 前100字有事发生
- [ ] 前300字有冲突或异样
- [ ] 前800字主角有动作/决定
- [ ] 本章至少一次信息增量
- [ ] 本章至少一次关系变化或立场变化
- [ ] 本章至少一个武侠识别点
- [ ] 小高潮落地，不悬空
- [ ] 章末能促使读者点下一章
- [ ] 无连续三段纯背景解释
- [ ] 有一句读者能记住的硬句

### 战斗规则
- 短战求狠，长战求变
- 每场战斗至少交代三件事中的两件：
  - 谁占信息优势
  - 谁占地形优势
  - 谁付出了代价
- 禁止玄幻光效化
- 禁止拆招空转

### 禁止项
- 禁止连续两章只铺局不落子
- 禁止主角连续两章没有主动行为
- 禁止整章最大价值只有“氛围感”
- 禁止朝堂戏长期压过江湖戏
- 禁止把接地气写成现代梗或无差别贫嘴
- 禁止所有角色都一个腔调：兵可以糙，主心骨不能塌

---

## Stage 5：平台审核

### 八维评分（总分100）
- 开篇抓力 15
- 节奏推进 15
- 人物魅力 15
- 武侠辨识度 15
- 爽点/兑现 10
- 悬念追读 10
- 语言质感 10
- 逻辑自洽 10

### 审核报告
```markdown
## 【审核报告】第X章 标题

整体评级：A / B / C / D
总分：XX/100

开篇抓力：XX/15
节奏推进：XX/15
人物魅力：XX/15
武侠辨识度：XX/15
爽点兑现：XX/10
悬念追读：XX/10
语言质感：XX/10
逻辑自洽：XX/10

是否具备起点首发可读性：是 / 否
最大掉追风险：
推荐修改优先级：先改开头 / 中段 / 章尾 / 主角动作

P0（必须改）：
P1（建议改）：
P2（可选改）：
```

---

## 最终铁律
- 不是写得像武侠就行，而是要让起点读者愿意继续追
- 克制不等于慢
- 留白不等于不兑现
- 好文气必须服务连载推进

# 沸腾之雪 · 技能索引

这里是《沸腾之雪》项目内的 Agent 技能目录。

这些 skill 不该混用，各自只负责自己的模块。

---

## 1. novel-flow

职责：流程调度

负责：
- 看上一章
- Beat Sheet
- 标题与钩子设计
- 逻辑冲突检查
- 写稿
- 审核

一句话：
**它只管“先做什么、后做什么”。**

不负责：
- 文笔
- 项目设定真假
- 单章核心思想判断

---

## 2. boiling-snow-novel-craft

职责：单章构思

负责：
- 这一章的核心思想
- 用什么事件承载
- 用谁的视角看
- 这一章的情绪是否成立

一句话：
**它只管“这一章怎么想”。**

不负责：
- 全书流程
- 项目全局时间线
- 通用文笔优化

---

## 3. boiling-snow-writing

职责：项目总原则

负责：
- 《沸腾之雪》的叙事结构约束
- 关键时间线与身份关系禁区
- 三绝、主角、导火索等项目硬事实
- 第一章与章尾留白的大原则

一句话：
**它只管“这本书怎么写才不歪”。**

不负责：
- 通用写作技法
- 起名
- 具体章节剧情长期堆积

备注：
这个 skill 目前仍偏胖，后续还需要继续瘦身，只保留真正的项目总原则。

---

## 4. 写手中枢

职责：通用文笔中枢

负责：
- 句子节奏
- 画面感
- 情绪推进
- 人物动作与对话
- 留白
- 去说明书感 / 去假文青 / 去 AI 味

一句话：
**它只管“怎么写得好”。**

不负责：
- 项目设定
- 时间线考据
- 章节流程

---

## 5. 起名中枢

职责：命名

负责：
- 章节名
- 卷名
- 序幕名
- 人物称号
- 文档标题

一句话：
**它只管“名字怎么起得准、有钩子、不俗”。**

不负责：
- 具体剧情
- 文笔润色
- 设定判断

---

## 推荐调用顺序

### 写正文时
1. 先用 `boiling-snow-writing` 校准项目硬约束
2. 再用 `boiling-snow-novel-craft` 定这一章的核心思想 / 事件 / 视角
3. 再用 `novel-flow` 跑流程
4. 写稿时由 `写手中枢` 保证文笔
5. 定标题时调用 `起名中枢`

### 只改标题时
- 直接调 `起名中枢`

### 只改文风时
- 直接调 `写手中枢`

### 只查项目设定时
- 直接调 `boiling-snow-writing`

---

## 当前状态判断

- `boiling-snow-novel-craft`：方向对，适合继续保留
- `boiling-snow-writing`：信息仍偏多，后续应继续瘦身
- `写手中枢`：已补上，后续会越来越重要
- `起名中枢`：已补上，后续章节命名统一走这里

# 写手中枢

## 职责边界

这份 skill 只负责一件事：
把文字写好。

负责：
- 句子节奏
- 画面感
- 情绪推进
- 人物说话与动作的真实感
- 留白与钩子
- 去说明书感、去假文青、去 AI 味

不负责：
- 项目设定真假
- 世界观硬约束
- 时间线考据
- 章节流程调度

这些分别交给：
- 项目 skill
- 时间线/设定文档
- novel-flow

## 核心原则

### 1. 先让人活，再让设定渗出来
错误：先讲身份、背景、世界观。
正确：先给动作、反应、处境，再让读者从细节里看懂人是谁。

### 2. 好句子不是华丽，是冷、准、硬、稳
- 冷：不替读者哭
- 准：一句只打一件事
- 硬：少虚词，少飘话
- 稳：节奏不乱，不炫技

### 3. 情绪不要说，要让它发生
错误：他很难过、她很愤怒、气氛很悲伤。
正确：用沉默、动作、停顿、环境变化去带出情绪。

### 4. 画面来自细节，不来自形容词堆砌
优先写：
- 光
- 冷热
- 声音
- 材质
- 气味
- 人的动作

少写：
- 很美
- 很震撼
- 很悲凉
- 很压抑

### 5. 留白比解释更重要
- 不抢答
- 不提前揭底
- 不把章尾写成答案公布
- 让读者先看见异样，再慢慢知道为什么

## 句子模块

### 短句
用来：
- 落刀
- 转气
- 收尾
- 提高压迫感

### 长句
用来：
- 蓄势
- 拖气
- 拉画面
- 形成心理压迫

规则：
- 一长一短，比全长或全短都稳
- 关键句尽量短
- 章尾最后一句尽量干净

## 人物模块

### 对话原则
- 每个人的话都必须带身份
- 不能像作者借人物发言
- 王爷、太监、江湖人、将军，说话口气必须不同

### 动作原则
- 动作不是摆设，是人物心理外露
- 一个摸杯、停步、抬眼、掩唇，都要有意义

## 钩子模块

### 好钩子
- 门开了
- 风放出去了
- 某件事要发生了
- 读者知道不对，但还不知道答案

### 坏钩子
- 直接揭身份
- 直接报名字
- 直接解释真相
- 作者站出来总结

## 去病模块

### 禁止
- 说明书口气
- 假文青
- 空抒情
- 一句里塞三层意思
- 角色一开口就全懂
- 形容词连发

### 常用自检
- 这句话是在写事，还是在解释事？
- 这段是在发光，还是在发空？
- 这个章尾是在开门，还是在抢答？

## 输出标准

一段文字合格时，应同时满足：
1. 读者能看见画面
2. 人物像活人，不像设定卡
3. 情绪是被感受到，不是被告知
4. 文字不解释过量
5. 收尾有后劲


## 连载读感补充

### 1. 句子要冷，段落要推着读者走
- 每300-500字最好有一次信息拐点
- 段落不能只是漂亮，要推进

### 2. 对话必须承担推进
- 对话不只是区分人物身份
- 还要推进关系、立场或信息

### 3. 战斗描写优先判断与变化
- 先写判断、试探、失手、反制
- 不要只写快、狠、冷、重

### 4. 自检问题
- 这段除了好看，还推进了什么？
- 这段景物有没有替代剧情？
- 这句硬句是不是能被记住，而不是只摆文气？
- 这一段读完后，读者是否更想往下滑？

### 连载禁止项
- 禁止连续两段以上纯氛围压场
- 禁止“人物沉默 + 风雪 + 灯火”反复做万能高级感
- 禁止一章反复强调同一层冷感
- 禁止过多“像……一样”的比喻稀释刀感

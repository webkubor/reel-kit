# Reel Studio 桌面工作台

## 方向与范围

用户在本次开发会话选择「浅色纸面、左表单右画布」，并明确要求新 Wails 产品接替原桌面实现。此文记录已选方向和当前 token，不宣称旧实现已有成熟设计体系。

主要任务：新建项目，输入逐句文案，可选导入图片，使用本机离线中文语音生成视频，播放并导出 MP4。UI 是桌面工作流；无营销页、SEO 或 GEO 要求。

## 布局与层级

- 左侧项目列表；顶部项目选择、新建、导入；内容左侧表单、右侧画面与工序。
- 主操作为「开始制作」，以陶土色强调。取消为次级操作，制作时阻止重复提交。
- 标题、说明与辅助文字分级。视频画布采用深底，其余界面保持浅色。
- 桌面最小宽度以 `main.go` 的窗口约束为准；验收覆盖 1024、1440 宽度。当前只承诺浅色主题。
- 编辑画面明确写「画面示意 · 最终以成片为准」；成片必须使用真实视频播放器。

## Token 与控件

界面 token 唯一入口：`frontend/tailwind.config.js`。组件样式在 `frontend/src/input.css`；构建后的 `dist` 不手改。

- 表面：paper / surface / raised；文本：ink / ink-mid / ink-lo / ink-dim。
- 品牌操作：accent / accent-deep / accent-soft。状态用 ok、err。
- 字阶：11、12、13、14、16、19、23；圆角：4、6、10。新增档位先更新配置和此文。
- Button 使用 btn + 尺寸 + variant；输入框使用 input；选择器共用 ReelSelect。
- 控件必须有可访问名称、键盘焦点、禁用/忙碌状态；项目和素材选择保留 aria 状态。
- 错误和任务文案允许选中复制。原生文件选择和保存由 Wails 调用系统对话框。
- 成片模板自身的画布坐标和字体尺寸属于视频内容，不作为桌面 UI token。

## 禁止项

不添加装饰渐变、玻璃卡片、营销 hero；不启动 Node 或本地 HTTP 业务服务；不将编辑示意当作成片验收证据；不将编译通过当作桌面交互通过。

## 验收

检查：新建、导入、输入、画幅选择、项目切换、任务恢复、制作/取消、历史成片播放、系统导出；检查正常、空、运行、失败、长文案状态。保存窗口专属截图，禁止截取用户其他应用。源码审查与实际窗口验收分别记录。

当前边界：项目草稿在进程内按项目保存，退出不保存草稿；素材、成片与任务记录落盘。编辑预览为示意，不承诺 WYSIWYG。正式 Apple 公证独立于 UI 验收。

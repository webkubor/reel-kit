# 素材分类规则与导入 SOP（muse-tv）

真源文档。视觉模型的素材怎么归类、怎么命名、怎么入库、怎么验证，都按这份执行。
改分类逻辑前先读这里；与代码不一致时以这里为准并修代码。

## 0. 核心原则

1. **角色是电影角色，不是真实的人。** 所有「角色」素材都是这个角色在剧里
   的形象（定妆立绘、三视图），不是演员或参考模特的照片。
2. **真人参考只是建模参考。** 真人照片（脸部参考等）仅供 AI 生成时参考长相
   气质，**永远不作为角色头像、不参与角色形象展示**。
3. **一个素材只归一类。** 分类互斥，按「视觉内容」判断，命名只作辅助。
4. **没把握就标待定。** 分类不清的素材宁可归入「待定」或「画面素材」，
   不硬塞进角色形象区。

## 1. 素材分类体系（六类，互斥）

| 类别 | 含义 | 视觉判定依据 | 命名建议 |
|---|---|---|--|
| **角色头像** | 该角色在剧中的形象特写（半身/脸部，单人，服装明确） | 人物为主体的近景/半身图；角色服装清晰；无多人物、无场景叙事 | `{角色名}-头像` |
| **定妆立绘** | 该角色完整形象的单人立绘（全身，站姿，服装明确，纯色或简单背景） | 全身单人、静态站姿、服装完整可见；背景干净 | `{角色名}-定妆-{装扮或序号}` |
| **三视图** | 同一角色的正面/侧面/背面三视角组合图（或单视角） | 同一人多个视角并列（前/侧/背），通常白底或灰底；是建模用图 | `{角色名}-三视图-{装扮或序号}` |
| **兵器与道具** | 角色专属的武器、面具、笛子等道具（通常无人物或仅局部） | 画面主体是器物；不是人物形象 | `{角色名}-武器-{道具名}` |
| **真人参考** | 建模参考用的真人照片（演员脸、气质参考） | 现实照片质感（人像摄影、真人五官）；或来源目录为「脸部参考」 | `{角色名}-真人参考-{来源}` |
| **画面素材** | 剧情画面、场景、带动作的叙事图、多人物图（不是角色配置物料） | 场景为主、人物在环境中、有动作叙事、多人物 | `{角色名}-画面-{描述}` |

判定优先级（一张图同时沾多个特征时）：**真人参考 > 兵器道具 > 三视图 > 定妆立绘 > 角色头像 > 画面素材**。
即：是真人照片 → 真人参考；主体是器物 → 兵器道具；多视角并列 → 三视图；
单人全身静态 → 定妆立绘；单人近景 → 角色头像；其余 → 画面素材。

## 2. 导入 SOP（新素材入库流程）

适用：从任何来源（fork 原项目、用户提供、中台生成）把素材登记到角色名下。

```
Step 1 来源登记
  记录来源：原项目目录（如 references/脸部参考、定妆照）、用户提供、中台生成。
  来源目录为「脸部参考」的 → 一律归「真人参考」，进不了角色形象区。

Step 2 视觉判定（人工或视觉模型，逐张）
  按第 1 节判定规则归类；多特征按优先级取最高。
  不确定的 → 「待定」，不猜。

Step 3 命名
  按第 1 节命名建议生成素材名：`{角色名}-{类别}-{描述}`。
  命名必须含类别关键词（头像/定妆/三视图/武器/真人参考/画面），
  供前端分组和出镜参考引用。

Step 4 入库
  图片登记到中台主体名下（role=standard/raw，名称=Step3 名字），
  并下载到本地素材库（media/ + studio.json），记录 sourceUrl。

Step 5 本地镜像刷新
  跑 RefreshCharacterCache，镜像里记录素材名与本地 assetId。

Step 6 验证（对照检查，人看截图）
  1) 角色库列表：头像 = 角色形象图（定妆/三视图），不得是真人参考；
     无角色形象 → 显示「待定头像」占位，不拿画面/真人凑。
  2) 角色详情：头像/定妆/三视图/兵器道具/真人参考分栏正确，无串类。
  3) 出镜提示词：@角色名 时带上的参考图分类与命名一致。
  4) 断网打开：头像从本地 /media/ 正常显示。
```

## 3. 角色库展示规则（前端）

- **列表头像**：只取「角色头像」类；没有时依次退回「定妆立绘」→「三视图」；
  都没有 → 显示统一「待定」占位（人形图标 + 待定头像），**绝不拿真人参考或画面素材凑**。
- **详情分栏**（互斥，缺哪个隐藏哪个）：角色头像 / 定妆立绘 / 三视图 /
  兵器与道具 / 真人参考（明确标注「真人参考 · 非角色形象，仅建模参考」）/
  画面素材（标注「不参与角色物料」）。
- **计数**：角色素材数（头像+定妆+三视图）与兵器数分开显示，不混。

## 4. 出镜参考规则（@角色名）

出镜时自动带上的参考图顺序：
1. 角色头像（锁定长相）
2. 选定装扮的定妆立绘
3. 三视图（辅助转面）
4. 兵器道具
真人参考**不上出镜参考**（它只是建模期素材，不是角色形象）。

## 5. 待定处理

- 角色没有头像/定妆/三视图 → 列表显示「待定头像」，详情相应分栏隐藏。
- 「待定」不是错误：等定妆后再补，或用户提供素材后按本 SOP 重新导入。

## 6. 历史遗留修正原则

对已有素材按本规则复查：
- 名字带「头像」但内容为真人照片 → 改名归入「真人参考」，头像位改待定。
- 名字带「定妆」但内容是场景叙事图 → 归「画面素材」。
- 同一张图多个用途 → 只归一类（优先级规则）。

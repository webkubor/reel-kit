muse-tv 1.9.0

本版把工作台按「项目类型」重组，并把「缺什么」如实标出来。

产品结构
- 项目类型：短剧（剧集 / 角色 / 场景）或短视频（素材与制作），新建时选，之后不可改。
  一个短剧项目里不再出现「产品短片」这种跨类型切换
- 首次进入有引导页：先检查 MUSE AV 登录态与 AI 配置，再新建项目
- AI 提供方可切换：MUSE AV 中台（默认）或直连模型服务；
  直连识别 MiniMax H3 模型族，并按其线格式适配（content 数组 + reference_image 角色标签）

素材
- 内置素材模板：角色五视图 / 三视图 / 定妆立绘 / 角色头像 / 兵器图 / 场景参考，
  一键批量出图，产物按分类规则自动命名归位
- 分类规则前后端统一（列表与详情不再把同一张图归到不同分区），
  真人参考不会被当成角色头像，三视图拼图不会被当成头像
- 角色改名后，镜像与素材库的名字同步更新

断网可用
- 角色、场景与场景参考图都有本机快照兜底；中台不可达时照常显示

剧集
- 从 YouTube 导入已发布剧集，工作台内直接播放；序章编号 0 排在最前
- 剧集完备度如实可见：只有发布链接、还没排角色与分镜的集标「待分镜」，
  本集状态面板写明缺什么，以及为什么这些信息视频里没有

工程
- 界面回归脚本：bash scripts/run-ui-regression.sh
- 发布前检查：bash scripts/preflight.sh <包目录>

已知限制（如实说明）
- 本包仅做本机 ad-hoc 签名，未做 Apple 公证；macOS 可能拦截首次启动
- 出镜（联网生成视频）与素材模板真生成需提交付费任务，本版未在验收中执行
- 验收期间屏幕一直锁定，原生窗口、菜单栏、系统文件选择器一次都没点过；
  界面验收均用无界面浏览器打开同一套前端完成
- 13 集的出场角色与分镜是空的：YouTube 只提供标题与链接，工作台已显式标出

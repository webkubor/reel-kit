四条流水线，填表就能出片

应用左侧是四条视频流水线，点进去中间是这条流水线的配置，右边是它跑出来的视频。 自包含安装包内含 Node、Chrome、FFmpeg 与 MuseAV CLI；配音引擎也一起打包，不用再单独装； 素材与成片留在你自己电脑上。

GitHub 项目推荐

输入仓库地址 → 分镜 → 逐句配音 → 带解说的项目介绍视频。

知识口播 / 观点解读

写一段脚本，一行一镜，逐句配音自动对时长；44 套视觉风格，没有素材也能先出片。

合成与导出

按顺序把素材、配音、BGM 合成成片，导出到本地项目。

第一次用，不用再装任何东西

配音引擎随应用一起打包，下载解压就能出声：不联网、不产生费用、 声音不出本机。macOS 与 Windows 是同一套模型、同一个调用方式。

只有「克隆自己的声音」和「设计音色」这两件事需要 VoxFlow （Apple 芯片的 Mac，本机推理）。它是可选的 —— 装不装都不影响出片， 也不影响自带引擎配音。

macOS 第一次打开会被 Gatekeeper 拦一下（这个包没做苹果公证）： 右键点应用选「打开」再点「打开」就行，或在终端里执行 xattr -dr com.apple.quarantine "/Applications/Reel Studio.app"。 Windows 同样没做代码签名，被 SmartScreen 拦时选「仍要运行」。

遇到问题怎么反馈：在「设置与反馈 → 运行日志」选择「导出排障报告」， 检查其中是否包含私人信息后，把报告附到 问题反馈。 Windows 启动闪退时，可在资源管理器输入 %TEMP% 查找 reel-studio-crash.log； 部分启动错误可能不会生成日志。Windows 版的图形界面仍在真实用户实测中，欢迎把遇到的问题直接发给我们。

图片与视频默认走 MuseAV 中台与 MiniMax；也可以在「设置与反馈 → 模型通道」里 填上你自己的中转站或厂商直连 —— 在设置页填一次就行，不用改配置文件， 密钥也不会出现在界面里。

命令行一行出片

准备一个图片目录，和一份一行一句的文案就能跑。完整参数见 开发者文档。

CLI

不需要先安装

npx github:webkubor/reel-kit make \
  --template sticker-promo \
  --title "新功能" \
  --assets ./shots \
  --caps ./captions.txt \
  --out out.mp4

本地优先,默认不上报

reel-kit 是 本地工具:素材、文案、模板、合成,全在你机器上跑。 CLI 工具 默认不开 telemetry——你的内容不会因为跑了 reel make 而被传到任何地方。

GitHub Pages 站只用作项目门面,可选集成 Plausible(隐私友好的无 cookie 埋点),见 docs/analytics-setup.md。

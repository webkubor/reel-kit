三件事,一个仓库

reel-kit 不是一个工具,是把"短视频生产"拆成三件事,各自有模块,但共享一个仓。 想做哪个就打开哪个,不用切换项目。

📣 推广

Studio 工作台 + 创作规范(CREATIVE_BIBLE),把"做好一个 IP"流程化:镜头台、角色库、集数、提示词实验室、批处理、推广位。

🎬 剪辑

命令行一行出片:reel make。5 套 HTML 模板、9 种 xfade 转场、长句字幕分镜、BGM 平滑接缝、念白驱动镜头时长。

✍️ 模板开发

20 套手绘风格配方 + 7 个生产期 Skill(写手/起名/世界书审计),模板用 HTML/CSS 写,所见即所得,改完直接用。

5 套模板 竖版 / 方形 / 横版 / 纯文字 · 一键切换

模板是 HTML/CSS 文件,改颜色、改布局、加 logo 都直接编辑。 模板作者不需懂 ffmpeg。

30 秒上手

两种形态,同一个引擎。命令行适合批处理和 CI,工作台适合人工调整和创作。

CLI

命令行一行出片

npm i -g @kubor/reel-kit

reel make \
  --template sticker-promo \
  --title "新功能" \
  --assets ./shots \
  --caps ./captions.txt \
  --out out.mp4

Studio 工作台

git clone webkubor/reel-kit
cd reel-kit
pnpm install
pnpm dev --filter @kubor/reel-studio
# → http://127.0.0.1:5273

本地优先,默认不上报

reel-kit 是 本地工具:素材、文案、模板、合成,全在你机器上跑。 CLI 工具 默认不开 telemetry——你的内容不会因为跑了 reel make 而被传到任何地方。

GitHub Pages 站只用作项目门面,可选集成 Plausible(隐私友好的无 cookie 埋点),见 docs/analytics-setup.md。

01 / 制作流程

从整部戏，
看到每一个镜头。

先建立项目，再按剧集推进。角色和场景统一管理，镜头记住它需要的素材。

01

建立项目

一部短剧对应一个项目，绑定 MUSE AV 工作区，让这部戏的角色和场景归到一起。

项目 / 工作区
02

准备角色与场景

在角色库查看人物设定和参考素材，在场景库保存画面描述与场景参考图。

角色库 / 场景库
03

逐集制作

为每集安排镜头，选择角色、装扮和场景；出镜素材与成片回到对应镜头。

剧集 / 镜头 / 成片

以上为开发版工作流。AI 出镜会连接中台并可能消耗额度；生成画面仍需要人工审阅。

02 / 数据与素材

知道素材在哪里，
也知道它属于谁。

01

角色与场景，在 MUSE AV

角色主体、场景主体和中台素材按工作区管理。工作台通过绑定的项目读取，使用时需要网络连接。

02

剧集与成片，在本机

桌面工作台的剧集、镜头与本地媒体保存在电脑上。请按自己的备份习惯保管这些数据。

03

创作过程，随时核对

镜头出镜失败或中断后可核对任务状态，避免在结果不明时重复提交。

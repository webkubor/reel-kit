把文案和素材，变成一条能直接发的短视频

Reel Studio：下载即用的桌面应用，macOS 与 Windows。
写好文案、选一个声音，逐句配音、自动配画面、合成导出 MP4。
画面会动（镜内缓推、字幕入场、转场），配乐自动垫底、随人声闪避。
配音默认走微软 Edge 在线神经语音（文字会发往微软，当前不按调用计费）；随包也带离线引擎，随时可切。

本机离线制作，文案变成短片

Reel Studio 1.6.0 使用 Wails + Go，左侧填写文案，右侧播放成片。 包内提供离线中文语音、Chrome 与 FFmpeg，无 Node 运行时、无本地 HTTP 业务服务。 素材与成片留在你自己电脑上。

项目与素材

新建项目、导入图片，按项目保存素材、任务记录与历史成片。

逐句离线配音

一行一句、一句一镜，按真实语音时长安排画面；最多 8 句，每句 80 字。

合成与导出

在应用里播放真实成片，通过系统保存对话框导出 MP4；制作中可以取消。

人物商品介绍

给产品或人物出一条介绍片：竖屏出镜画面满屏，横屏左图右文，画幅决定版式。

离线资源随包提供

中文配音使用 sherpa-onnx：不联网、不按调用计费。缺少资源时显示错误，不偷偷切换到云服务。

签名状态：ad-hoc 签名、未 Apple 公证，macOS 可能拦截首次启动。当前需要手动下载更新。

MVP 边界：编辑画面为示意；草稿只在当前进程内暂存。尚未提供云 TTS、声音克隆、AI 素材生成或旧项目自动迁移。

失败时查看「制作过程」，复制错误并移除私人路径后提交 问题反馈。

桌面应用底下，是一套能自己搭的引擎

仓库另外提供独立的 CLI/库，适合批量出片和模板开发；以下能力属于 CLI，不代表桌面 MVP 已开放全部入口。

🎬 剪辑

20 套手绘风格配方、44 套知识短视频视觉风格，模板用 HTML/CSS 写，所见即所得，改完直接用。

模板是 HTML/CSS 文件，改颜色、改布局、加 logo 都直接编辑。 模板作者不需懂 ffmpeg。

命令行一行出片

准备一个图片目录，和一份一行一句的文案就能跑。这条命令直接从 Git 仓库执行 —— 本项目不发布 npm 包，用户一律走应用下载。完整参数见 开发者文档。

CLI

不需要先安装

npx github:webkubor/reel-kit make \
  --template sticker-promo \
  --title "新功能" \
  --assets ./shots \
  --caps ./captions.txt \
  --out out.mp4

本地优先,默认不上报

reel-kit 是 本地工具:素材、文案、模板、合成,全在你机器上跑。 CLI 工具 默认不开 telemetry——你的内容不会因为跑了 reel make 而被传到任何地方。

GitHub Pages 站只用作项目门面,可选集成 Plausible(隐私友好的无 cookie 埋点),见 docs/analytics-setup.md。

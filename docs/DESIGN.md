# muse-tv 官网设计

官网延续 `apps/reel-studio-wails/DESIGN.md` 的品牌方向：近黑冷灰、银白冷光、克制的钢蓝强调，以及清晰舒适的留白。用户明确要求官网名称和视觉与 muse-tv 工作台一致，原白底珊瑚色 Reel Studio 官网不再沿用。

官网是面向新用户的静态产品介绍，不是工作台本身。首页说明短剧工作流、中台与本地的数据边界、已发布版本与开发版的区别。例图使用真实项目素材并标注来源；不能将示意界面冒充实际软件截图，也不能将开发版功能宣称为已发布安装包功能。

`style.css` 的根变量定义官网语义色和尺寸；颜色从桌面 Tailwind 配置取值，适配宽屏和窄屏，交互元素须有可见焦点。站点保持无构建、无 JavaScript 依赖。

2026-11-18：按用户反馈统一官网与工作台视觉。GitHub 最新公开版仍为 Reel Studio 1.8.1；项目、剧集与镜头工作流属于后续开发版，在新版本发布前须明确区分。
